# Quiz Game

A browser-based quiz application built with **HTML, CSS and JavaScript**. The project separates the quiz page, styling and JavaScript assets into dedicated folders.

## Features
- Interactive quiz interface
- Separate quiz page
- Organized HTML, CSS and JavaScript assets
- Runs locally in a modern web browser


## Run Locally
1. Clone: `git clone https://github.com/Lokeshkumardulla/Quiz-game.git`
2. Open `Quiz game/index.html` in a modern browser.

No package installation or build step is required for the current static front end.
