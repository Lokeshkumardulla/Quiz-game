# Quiz Game

A browser-based quiz game built with HTML, CSS, and JavaScript. The application provides a simple interface for users to start a quiz and answer questions.

## Project structure

```text
Quiz-game/
├── Quiz game/
│   ├── index.html
│   ├── quiz.html
│   ├── css/
│   ├── js/
│   └── res/
└── README.md
```

## Run locally

1. Clone this repository:
   ```bash
   git clone https://github.com/Lokeshkumardulla/Quiz-game.git
   ```
2. Open the `Quiz game/index.html` file in your browser.
3. Follow the on-screen instructions to use the quiz.

No backend server is required for this static front-end project.
